### Создание и наполнение Базы данных SQL
______________________________________________________

#### Описание
Для нужд пользователей навигационной компании была создана база данных с автоматическим заполнененением данными, полученными с помощью парсинга.
_______________________________________________________
#### Навыки и инструменты

- sqlite3
- sqlalchemy ORM 2.0
- pandas
- UUID

_______________________________________________________
#### Общий вывод
Использование Alchemy ORM для создания SQL баз данных на Pyton-e позволяет оперативно создать БД и наполнить большим количеством данных. 
35000 записей разбирались, собирались и загружались 2 минуты.
